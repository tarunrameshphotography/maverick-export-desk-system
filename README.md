# Maverick Export Desk System

This folder breaks the 14 Sep 2026 strategy dossier (`DELIVERABLES/Maverick Minds Export Desk Strategy.html` / `.docx` / `.pdf`) into standalone files, one per section, so future work — content production, automation build, LEAP design — can reference a single part without opening the full 1,100-line document. It mirrors the structure used for the Alive by VK content system.

The combined document is still the canonical read-once version and the one to send the founder. Everything below is the same content, split for reuse. If the two ever disagree, the combined `DELIVERABLES` file is source of truth until this folder is re-split from it.

## Folder guide

- **BRAND/** — who Maverick Minds is, what it stands for, and how it should sound.
- **MARKET/** — the external landscape: the 2026 policy environment and the competitor map.
- **AUDIENCE/** — the five segments and four buyer journeys.
- **STRATEGY/** — channel-level plans (LinkedIn, Instagram) and the content-franchise architecture that feeds both.
- **INTELLIGENCE SYSTEM/** — the operating system behind the Desk: how research, scoring, drafting, approval, automation and the database fit together. Treat this folder as the spec for whoever builds the pipeline.
- **DELIVERABLES/** — the combined document in three formats, the logo used in it, and the 30-day editorial plan as a standalone reference.
- **SOURCE/** — the research trail.

## Evidence labels used throughout

`[FACT]` verified against a source · `[INTERPRETATION]` our reading of facts · `[FORECAST]` a call about the future · `[OPINION]` a judgement · `[VERIFY]` confirm on a primary source before publishing.
